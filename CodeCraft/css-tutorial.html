1. What Is CSS?

CSS stands for Cascading Style Sheets. While HTML provides structure, CSS provides presentation: colors, fonts, spacing and layout. A CSS rule has a selector (what to style) and a declaration block (how to style it).

rule-anatomy.css
h1 {            /* selector */
  color: navy;  /* property: value; */
  font-size: 2rem;
}

2. Types of CSS: Inline, Internal, External

TypeWhere it goesWhen to use it
Inlinestyle attribute on one elementRarely. Hard to maintain.
Internal<style> element in the <head>Quick experiments or one-page demos.
ExternalA separate .css file linked from the HTMLBest practice for real websites.
three-ways.html
<!-- 1. Inline -->
<p style="color: crimson;">Inline styled text</p>

<!-- 2. Internal (in the head) -->
<style>
  p { color: crimson; }
</style>

<!-- 3. External (recommended) -->
<link rel="stylesheet" href="css/style.css">

3. Selectors and Properties

selectors.css
/* Element selector: every paragraph */
p { line-height: 1.6; }

/* Class selector: elements with class="card" */
.card { padding: 1rem; }

/* ID selector: the element with id="intro" (use sparingly) */
#intro { font-size: 1.2rem; }

/* Descendant selector: links inside the nav */
nav a { text-decoration: none; }

/* Pseudo-class: a link while hovered */
a:hover { text-decoration: underline; }

Classes are the most useful selector because you can reuse them on as many elements as you like.

4. Colors and Backgrounds

Colors can be written as names (tomato), hex codes (#3b82f6), rgb() or hsl() values. Backgrounds can be colors, images or gradients.

colors.css
.banner {
  background: linear-gradient(135deg, #3b82f6, #22d3ee);
  color: #0b1120;
  padding: 1.5rem;
  border-radius: 12px;
}
Output
A gradient banner
Check contrast

Text must stand out clearly from its background. WCAG recommends a contrast ratio of at least 4.5:1 for normal text.

5. Typography and Fonts

typography.css
body {
  font-family: "Inter", Arial, sans-serif; /* fallbacks after the first font */
  font-size: 1rem;
  line-height: 1.7;      /* comfortable reading */
}
h1 {
  font-weight: 700;
  letter-spacing: -0.01em;
}

Web fonts such as those from Google Fonts are linked in the HTML <head>. Always list a fallback font. Use rem units so text respects the user’s browser settings.

6. Margins, Padding and Borders

  • Padding is space inside an element, between its content and its border.
  • Border is the line around the padding.
  • Margin is space outside the border, separating the element from its neighbors.
spacing.css
.box {
  padding: 1rem 1.5rem;          /* top/bottom  left/right */
  border: 2px solid #3b82f6;
  border-radius: 10px;
  margin: 2rem auto;             /* auto centers a block with a set width */
}

7. The CSS Box Model

Every element is a rectangular box made of four layers: content, padding, border and margin.

box-sizing.css
/* Makes width include padding and border: far easier to reason about */
*, *::before, *::after {
  box-sizing: border-box;
}

8. Display and Positioning

The display property controls how an element takes up space. block elements (like <div> and <p>) fill the full width and start on a new line. inline elements (like <a> and <span>) flow within text. none hides an element entirely.

positionBehavior
staticDefault normal flow
relativeOffset from its normal place; becomes a reference point for children
absolutePlaced relative to the nearest positioned ancestor
fixedStays in place relative to the viewport while scrolling
stickyScrolls normally, then sticks at a set offset
sticky-header.css
.site-header {
  position: sticky;
  top: 0;               /* sticks to the top edge when scrolling */
  z-index: 100;
}

9. Flexbox

Flexbox arranges items in a single row or column and makes spacing and alignment simple. Add display: flex to a container and its children become flex items.

flexbox.css
.toolbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 1rem;
}
Output
LogoMenu itemButton

justify-content spreads items along the main axis; align-items aligns them on the other axis; flex-wrap: wrap lets items move to a new line on small screens.

10. CSS Grid

Grid lays out content in rows and columns at the same time, ideal for card layouts and page templates.

grid.css
.cards {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 1rem;
}

Flexbox or Grid?

Use Flexbox for one-dimensional layouts (a row of buttons, a nav bar). Use Grid for two-dimensional layouts (a page or a card gallery). They work well together.

A responsive grid without media queries:

auto-fit-grid.css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 1rem;
}

11. Hover Effects and Transitions

A transition smooths a change between two states. Always style :focus-visible too so keyboard users get the same feedback.

button.css
.btn {
  background: #3b82f6;
  color: #fff;
  padding: 0.7rem 1.4rem;
  border-radius: 999px;
  transition: transform 0.2s, background 0.2s;
}
.btn:hover,
.btn:focus-visible {
  background: #2563eb;
  transform: translateY(-2px);
}
Output (hover or focus the button)
Hover me

Respect users who prefer less motion with @media (prefers-reduced-motion: reduce).

12. Media Queries

A media query applies CSS only when a condition is true, usually the width of the screen.

media-query.css
.cards {
  display: grid;
  grid-template-columns: 1fr;            /* mobile first: one column */
}

@media (min-width: 768px) {
  .cards { grid-template-columns: repeat(2, 1fr); }
}

@media (min-width: 1024px) {
  .cards { grid-template-columns: repeat(3, 1fr); }
}

This is the mobile-first approach: write styles for small screens first, then add min-width queries for larger ones.

13. Responsive Design Basics

  1. Add the viewport meta tag in your HTML head so phones scale the page correctly.
  2. Use flexible units: percentages, rem, fr and max-width instead of fixed pixel widths.
  3. Make images fluid with max-width: 100%; height: auto;.
  4. Use Flexbox and Grid to let content rearrange naturally.
  5. Add media queries only where the layout needs to change.
  6. Test by resizing the browser window or using device mode in developer tools.
responsive-basics.css
img {
  max-width: 100%;
  height: auto;
}
.container {
  width: min(100% - 2rem, 1100px);
  margin-inline: auto;
}

Mini Exercise: Style Your Personal Webpage

Your task

Take the profile.html you built in the HTML exercise and style it with an external stylesheet named style.css.

Requirements checklist:

  • Link style.css in the head of profile.html.
  • Set a readable font, a background color and a text color with good contrast.
  • Center the content with a max-width and margin: 0 auto.
  • Style the header with a background color and padding.
  • Turn your list of hobbies into a Flexbox row of “tag” items.
  • Add a hover effect to your link.
  • Add one media query that adjusts padding on small screens.

Starter code:

style.css
* { box-sizing: border-box; }

body {
  font-family: Arial, sans-serif;
  line-height: 1.6;
  background: #f8fafc;
  color: #0f172a;
  margin: 0;
}

header {
  background: #0b1120;
  color: #f1f5f9;
  padding: 2rem 1rem;
  text-align: center;
}

main {
  max-width: 42rem;
  margin: 0 auto;
  padding: 1.5rem 1rem;
}
