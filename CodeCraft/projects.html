Project Guides

1. Personal Portfolio Website

Build a small site that introduces you, shows your projects and tells visitors how to get in touch.

MediumHTML5CSS3FlexboxGrid

Skills you will develop: semantic page structure, multi-page navigation, card layouts, consistent styling.

Outline:

  1. Sketch the pages: Home, About, Projects, Contact.
  2. Create the HTML for the shared header and footer, and copy it to each page.
  3. Write the hero section with your name and a one-line introduction.
  4. Create a grid of project cards, each with an image, title and short description.
  5. Style everything in one external stylesheet using CSS variables for your colors.
  6. Add a media query so the navigation and grid work on mobile.
portfolio-starter.html
<header>
  <nav aria-label="Main">
    <a href="index.html">Home</a>
    <a href="about.html">About</a>
    <a href="projects.html">Projects</a>
    <a href="contact.html">Contact</a>
  </nav>
</header>
<main>
  <section class="hero">
    <h1>Hi, I'm Your Name</h1>
    <p>I'm learning to build websites.</p>
  </section>
</main>

2. Responsive Landing Page

Create a single page that promotes an idea, club or product, with a clear call-to-action button.

EasyHTML5CSS3Media queries

Skills you will develop: hero layouts, typography hierarchy, buttons, responsive columns.

Outline:

  1. Pick a topic and write a headline, a short description and a button label.
  2. Build the sections: hero, three features, call to action, footer.
  3. Style the hero with a background color or gradient and large text.
  4. Lay the features out with a Grid that uses auto-fit.
  5. Check the page at 320px, 768px and 1200px widths.
landing-starter.css
.hero {
  padding: 4rem 1rem;
  text-align: center;
  background: linear-gradient(135deg, #1d4ed8, #0891b2);
  color: #fff;
}
.features {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 1rem;
}

3. Restaurant Menu Website

Design a menu page for a real or imaginary restaurant, organized by category.

EasyHTML5CSS3Lists

Skills you will develop: headings and lists, typography, spacing, simple grid layouts.

Outline:

  1. List categories such as Starters, Mains and Desserts.
  2. Mark up each dish with a name, description and price.
  3. Choose two fonts and a restrained color palette.
  4. Use Flexbox so each dish name and price sit on the same line.
  5. Place categories in a two-column Grid on wide screens.
menu-starter.html
<section>
  <h2>Starters</h2>
  <article class="dish">
    <h3>Tomato Soup</h3>
    <p>Slow-cooked tomatoes with fresh basil.</p>
    <p class="price">$6</p>
  </article>
</section>
Review: Flexbox

4. Product Showcase Page

Present one product with a large image, a feature list and a specifications table.

MediumHTML5CSS3GridTables

Skills you will develop: two-column layouts, image handling, tables, hover states.

Outline:

  1. Choose a product (a real item you own works well) and gather one or two images you are allowed to use.
  2. Create a two-column layout with the image on one side and the details on the other.
  3. Add a feature grid with icons or short headings.
  4. Add a specifications table with proper header cells.
  5. Stack the columns on small screens with a media query.
product-starter.css
.product {
  display: grid;
  gap: 2rem;
}
@media (min-width: 768px) {
  .product { grid-template-columns: 1fr 1fr; }
}
.product img { max-width: 100%; height: auto; border-radius: 12px; }
Review: CSS Grid

5. Photography Gallery

Display your own photos in a tidy grid with captions.

EasyHTML5CSS3GridImages

Skills you will develop: the figure element, image sizing, grid layouts, hover effects, alt text.

Outline:

  1. Choose 6–9 photos you took yourself and resize them for the web.
  2. Wrap each image and caption in a <figure> with <figcaption>.
  3. Write meaningful alt text for each photo.
  4. Create an auto-fit grid and make images fill their cells with object-fit: cover.
  5. Add a subtle hover transition.
gallery-starter.css
.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 1rem;
}
.gallery img {
  width: 100%;
  aspect-ratio: 4 / 3;
  object-fit: cover;
  border-radius: 10px;
  transition: transform 0.25s;
}
.gallery img:hover { transform: scale(1.03); }

6. Simple Blog Layout

Build a readable blog home page with article previews and a sidebar.

MediumHTML5CSS3GridSemantic HTML

Skills you will develop: semantic article markup, readable line lengths, sidebar layouts, consistent components.

Outline:

  1. Plan the layout: header, main column of posts, sidebar, footer.
  2. Mark up each post preview as an <article> with a heading, date and summary.
  3. Put the sidebar in an <aside> with an “About” blurb and a list of categories.
  4. Use Grid to place the sidebar beside the posts on wide screens only.
  5. Keep body text between roughly 60 and 80 characters per line for readability.
blog-starter.css
.layout {
  display: grid;
  gap: 2rem;
}
@media (min-width: 900px) {
  .layout { grid-template-columns: minmax(0, 2fr) 1fr; }
}
article p { max-width: 70ch; }
