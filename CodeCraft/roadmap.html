Your Web Development Learning Roadmap

Ten clear stages, each with a goal and a project to try. Move at your own pace and spend as long as you need on each stage.

How to use this roadmap

Finish one stage before starting the next. Time estimates assume a few hours of practice per week and are only rough guides. Everyone learns at a different speed.

  1. 1

    Understand How Websites Work

    Time: 1–2 daysLevel: Beginner

    Objectives: Explain what a browser, a server and a URL are. Describe the roles of HTML, CSS and JavaScript.

    Suggested activity: Open any site, press F12 and explore its HTML in the developer tools.

    Read: How websites work
  2. 2

    Learn HTML Fundamentals

    Time: 1–2 weeksLevel: Beginner

    Objectives: Build a valid HTML5 page with headings, text, links, images, lists, tables and a form, using semantic elements.

    Suggested project: A personal profile page.

    Start the HTML tutorial
  3. 3

    Learn CSS Fundamentals

    Time: 2–3 weeksLevel: Beginner

    Objectives: Use selectors, colors, fonts and the box model to style a page, and organize CSS in an external file.

    Suggested project: Style your personal profile page.

    Start the CSS tutorial
  4. 4

    Build Simple Web Layouts

    Time: 2 weeksLevel: Beginner

    Objectives: Create navigation bars, card rows and multi-column pages using Flexbox and Grid.

    Suggested project: A restaurant menu page.

    Practice with Flexbox and Grid
  5. 5

    Understand Responsive Design

    Time: 1–2 weeksLevel: Beginner

    Objectives: Make layouts adapt to phones, tablets and desktops using flexible units, fluid images and media queries.

    Suggested project: A responsive landing page.

    Read: Responsive design basics
  6. 6

    Practice with Mini Projects

    Time: 3–4 weeksLevel: Beginner

    Objectives: Plan, build and refine several small sites on your own. Practice reading documentation and fixing bugs.

    Suggested projects: Product showcase, photography gallery, simple blog layout.

    Browse beginner projects
  7. 7

    Learn Basic JavaScript Concepts

    Time: 4–6 weeksLevel: Beginner to intermediate

    Objectives: Understand variables, functions, conditions, loops and how JavaScript changes a page through the DOM.

    Suggested project: A page with a working mobile menu toggle or a simple form validator.

    Find free JavaScript learning sites
  8. 8

    Build a Complete Portfolio Website

    Time: 2–4 weeksLevel: Intermediate

    Objectives: Combine everything into a multi-page, responsive, accessible portfolio that presents you and your work.

    Suggested project: Home, about, projects and contact pages.

    See the portfolio project guide
  9. 9

    Learn Git and GitHub Fundamentals

    Time: 1–2 weeksLevel: Intermediate

    Objectives: Track changes with commits, understand repositories and branches, and push a project to GitHub.

    Suggested activity: Put your portfolio in a GitHub repository.

    Find Git and GitHub learning resources
  10. 10

    Publish Your First Website

    Time: 1–3 daysLevel: Intermediate

    Objectives: Put your site online using a free static hosting service and share the link.

    Suggested activity: Publish your portfolio and test it on a phone.

    Read: How do I publish my site?
