What Is Web Development?

Web development is the work of building websites and web applications. A website can be as simple as a single page that introduces you, or as complex as an online store or social network. All of them are built from a small set of core technologies that you can learn step by step.

People often split the work into two areas: the part visitors see and interact with, and the part that runs behind the scenes. We call these the frontend and the backend.

Frontend vs. Backend Development

FrontendBackend
What it isEverything the visitor sees and uses in the browserCode and data on a server that the visitor never sees
ExamplesLayouts, buttons, menus, forms, colors, animationsUser accounts, databases, payments, sending email
Core technologiesHTML, CSS, JavaScriptLanguages such as Python, JavaScript (Node.js), PHP, Java and databases

CodeCraft focuses on frontend fundamentals. They are the best place to start because you can see results immediately, with no server required.

How Websites Work

  1. You type an address (a URL) into your browser or click a link.
  2. The browser sends a request to a web server, a computer that stores the website’s files.
  3. The server responds with files: HTML, CSS, images and sometimes JavaScript.
  4. The browser reads those files and draws the page on your screen.
Good to know

When you build a page on your own computer, your browser can open the file directly. You do not need a server to learn HTML and CSS.

Tools You Need to Begin

You need only two things, and both are free.

  • A web browser. Chrome, Firefox, Edge or Safari all work. The browser reads your code and shows the page. It also has built-in developer tools for inspecting and debugging.
  • A text editor. A text editor is a program for writing code as plain text. Visual Studio Code is a popular free choice with helpful features such as color-coded code and auto-complete. Avoid word processors like Microsoft Word, which add hidden formatting.

Tutorial: Build Your First Website

  1. Create a project folder

    Make a new folder on your computer called my-first-site. Keeping all of a website’s files in one folder makes them easy to find and link together.

  2. Create an HTML file

    Open your editor, create a new file and save it inside the folder as index.html. The name index.html is the traditional name for a site’s home page.

  3. Add the basic structure

    Type or paste this code into the file:

    index.html
    <!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>My First Website</title>
</head>
<body>
  <h1>Hello, world!</h1>
  <p>This is my very first web page.</p>
</body>
</html>

    The <title> appears on the browser tab. Everything inside <body> appears on the page.

  4. Open it in your browser

    Save the file, then double-click it in your folder. It opens in your browser and you will see your heading and paragraph.

  5. Add some style with CSS

    Create a second file in the same folder named style.css:

    style.css
    body {
  font-family: Arial, sans-serif;
  max-width: 40rem;
  margin: 2rem auto;
  padding: 0 1rem;
  background: #f8fafc;
  color: #0f172a;
}

h1 {
  color: #2563eb;
}

  6. Link the CSS to your HTML

    Add this line inside the <head> of index.html, just below the title:

    index.html (inside head)
    <link rel="stylesheet" href="style.css">

    Save both files and refresh the browser. The page now has a new font, a light background and a blue heading. You have built a styled website.

Beginner Tips and Common Mistakes

Tips for success
  • Type the code yourself instead of only copying it. It builds muscle memory.
  • Change one thing at a time, save, and refresh to see what happened.
  • Practice a little every day. Short, regular sessions beat rare marathons.
  • Use your browser’s developer tools (press F12) to inspect any page.
Common mistakes
  • Forgetting to save before refreshing the browser.
  • Missing closing tags such as </p>, which can break the layout.
  • Wrong file names or paths. style.css and Style.css can be different files.
  • Using a word processor instead of a plain text editor.
