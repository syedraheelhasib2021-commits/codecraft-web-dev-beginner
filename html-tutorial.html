1. Introduction to HTML

HTML stands for HyperText Markup Language. It is a markup language: you wrap content in elements that tell the browser what each piece of content is, such as a heading, a paragraph or a link.

An element usually has an opening tag, content and a closing tag:

element-anatomy.html
<p class="intro">This is a paragraph element.</p>
<!-- <p> opens, </p> closes, class="intro" is an attribute -->

Tags are the names in angle brackets. Attributes such as class add extra information and always go inside the opening tag.

2. HTML Document Structure

Every HTML page uses the same skeleton:

index.html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Page title shown on the browser tab</title>
</head>
<body>
  <!-- Everything visible goes here -->
</body>
</html>
  • <!DOCTYPE html> tells the browser this is modern HTML5.
  • <html lang="en"> is the root element. The lang attribute helps screen readers pronounce text correctly.
  • <head> holds information about the page: character set, title and links to stylesheets.
  • <meta name="viewport"> makes the page scale properly on phones.
  • <body> contains everything people see.

3. Headings and Paragraphs

HTML has six heading levels, <h1> (most important) to <h6>. Use one <h1> per page for the main topic, then <h2> for sections, <h3> for subsections, and so on without skipping levels.

headings.html
<h1>Healthy Cooking</h1>
<h2>Breakfast Ideas</h2>
<p>A good breakfast gives you energy for the day.</p>
<h3>Quick oatmeal</h3>
<p>Ready in five minutes with just three ingredients.</p>
Tip

Choose headings for meaning, not size. Use CSS to change how big a heading looks.

5. Links and Images

Links use the <a> (anchor) element with an href attribute giving the destination. Images use the self-closing <img> element with src (the file) and alt (a text description).

links-images.html
<!-- Link to another website -->
<a href="https://developer.mozilla.org/">Visit MDN Web Docs</a>

<!-- Link to another page in your site -->
<a href="about.html">About me</a>

<!-- An image with alternative text -->
<img src="images/sunset.jpg" alt="Orange sunset over a calm sea" width="600" height="400">
Why alt text matters

The alt text is read aloud by screen readers and shown if the image cannot load. Describe what the image shows. If an image is purely decorative, use an empty alt="".

6. Ordered and Unordered Lists

lists.html
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

<ol>
  <li>Plan the page</li>
  <li>Write the HTML</li>
  <li>Add the CSS</li>
</ol>
Browser output
  • HTML
  • CSS
  • JavaScript
  1. Plan the page
  2. Write the HTML
  3. Add the CSS

Use <ul> when order does not matter (bullets) and <ol> when it does (numbers).

7. Tables

Tables display data in rows and columns. Use them for data, not for page layout.

table.html
<table>
  <caption>Weekly study plan</caption>
  <thead>
    <tr><th scope="col">Day</th><th scope="col">Topic</th></tr>
  </thead>
  <tbody>
    <tr><td>Monday</td><td>HTML basics</td></tr>
    <tr><td>Wednesday</td><td>CSS colors</td></tr>
  </tbody>
</table>

<tr> is a row, <th> a header cell and <td> a data cell. The scope attribute tells assistive technology whether a header applies to a column or row.

8. Forms and Input Fields

Forms collect information from visitors. Every input needs a <label> connected through matching for and id values.

form.html
<form action="#" method="post">
  <label for="name">Your name</label>
  <input type="text" id="name" name="name" required>

  <label for="email">Email address</label>
  <input type="email" id="email" name="email" required>

  <label for="topic">Favorite topic</label>
  <select id="topic" name="topic">
    <option>HTML</option>
    <option>CSS</option>
  </select>

  <label for="msg">Message</label>
  <textarea id="msg" name="msg" rows="4"></textarea>

  <button type="submit">Send</button>
</form>

Common input types include text, email, password, number, checkbox, radio and date. The required attribute asks the browser to check the field before submitting. A form that really sends data also needs server-side code, which is a later topic.

9. Semantic HTML5 Elements

Semantic elements describe their purpose, which helps search engines, screen readers and other developers understand your page.

semantic.html
<body>
  <header>
    <nav aria-label="Main"> ... links ... </nav>
  </header>
  <main>
    <article>
      <h1>Article title</h1>
      <section> ... </section>
    </article>
    <aside> Related links </aside>
  </main>
  <footer> Copyright information </footer>
</body>
  • <header> – introductory content or navigation
  • <nav> – a block of navigation links
  • <main> – the main content, used once per page
  • <section> and <article> – grouped or self-contained content
  • <aside> – related side content
  • <footer> – closing information for the page or section

10. Accessibility Fundamentals

Accessible pages work for everyone, including people who use screen readers, keyboards or magnification. Good HTML does most of the work.

  • Write meaningful alt text on images.
  • Use headings in a logical order and semantic landmarks such as <main> and <nav>.
  • Connect every form control to a <label>.
  • Use descriptive link text such as “Read the CSS guide”, not “click here”.
  • Set the page language with <html lang="en">.
  • Make sure everything works with the keyboard alone (Tab, Enter, Space).

11. Common Beginner Mistakes

  • Unclosed tags. Always close elements such as <p>, <div> and <li>.
  • Wrong nesting. Close tags in reverse order: <p><strong>text</strong></p>.
  • Skipping heading levels or picking headings for their size.
  • Missing alt text on meaningful images.
  • Using tables for layout. Use CSS for layout.
  • Broken file paths. Check spelling, capital letters and folders.

12. Practical Example: A Recipe Card

Here is a small page that combines several elements you have learned.

recipe.html
<article>
  <h1>Simple Tomato Pasta</h1>
  <img src="pasta.jpg" alt="A bowl of tomato pasta with basil" width="480" height="320">
  <p>A quick dinner for <strong>two people</strong> in about 20 minutes.</p>

  <h2>Ingredients</h2>
  <ul>
    <li>200 g pasta</li>
    <li>1 can chopped tomatoes</li>
    <li>2 cloves of garlic</li>
  </ul>

  <h2>Method</h2>
  <ol>
    <li>Boil the pasta until tender.</li>
    <li>Simmer the tomatoes and garlic for 10 minutes.</li>
    <li>Mix together and serve.</li>
  </ol>
</article>

Notice how the headings, lists and the <article> wrapper describe the meaning of the content before any styling is applied.

Mini Exercise: Create a Personal Profile Page

Your task

Create a file named profile.html and build a page about yourself using only HTML.

Requirements checklist:

  • Use the full HTML5 document structure with a descriptive <title>.
  • Include a <header>, <main> and <footer>.
  • One <h1> with your name, plus at least two <h2> sections (for example “About me” and “My interests”).
  • A paragraph about yourself and a photo with meaningful alt text (optional).
  • An unordered list of hobbies and an ordered list of goals.
  • A link to a website you like.

Starter code:

profile.html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Your Name – Personal Profile</title>
</head>
<body>
  <header>
    <h1>Your Name</h1>
  </header>
  <main>
    <section>
      <h2>About me</h2>
      <p>Write two or three sentences here.</p>
    </section>
    <!-- Add your interests, goals and a link below -->
  </main>
  <footer>
    <p>Made with HTML.</p>
  </footer>
</body>
</html>

When you are done, your page will look plain. That is expected. In the next lesson you will style it with CSS.
