Resources & Tools

A short, trustworthy list of tools and references. Each entry explains why it helps beginners. Links open the official sites.

A note on links

These are official websites run by other organizations. Features and pricing can change, so check each site for current details. External links open in the same tab; use your browser’s back button to return.

Code Editors

Visual Studio Code

A free, popular editor with color-coded syntax, auto-complete and thousands of extensions. A great first editor because it works on Windows, macOS and Linux.

code.visualstudio.com

Sublime Text

A fast, lightweight editor that is pleasant if you prefer something minimal. It can be used free for evaluation; check the site for licensing.

sublimetext.com

Notepad++ (Windows)

A simple, free editor for Windows users who want something small and quick to open.

notepad-plus-plus.org

Browser Developer Tools

Chrome DevTools

Inspect any element, edit CSS live, test phone screen sizes and find errors. Press F12 in Chrome to open it.

DevTools documentation

Firefox Developer Tools

Excellent visual tools for CSS Grid and Flexbox that show the layout directly on the page, which is very helpful while learning.

Firefox DevTools docs

Edge DevTools

Built on the same engine as Chrome’s tools, with accessibility-focused features. Handy if you use Microsoft Edge.

Edge DevTools guide

HTML & CSS Reference Documentation

MDN Web Docs

The most trusted reference for HTML, CSS and JavaScript, with clear explanations, examples and browser support. Bookmark it first.

developer.mozilla.org

W3C

The organization that develops web standards. Its site links to the official specifications and to accessibility guidelines (WCAG).

w3.org

CSS-Tricks

Practical articles and guides, including well-known visual guides to Flexbox and Grid that make tricky layouts easier to understand.

css-tricks.com

Free Learning Websites

freeCodeCamp

A nonprofit offering free, project-based courses in HTML, CSS and JavaScript with exercises you can do in the browser.

freecodecamp.org

web.dev Learn

Free courses from Google on modern web topics such as responsive design, CSS and accessibility.

web.dev/learn

GitHub

The home of Git-based code hosting. Create a free account to store projects, practice version control and publish sites with GitHub Pages.

github.com

Design Inspiration

Awwwards

A showcase of well-designed websites. Browse it to see what modern layouts and typography can look like.

awwwards.com

Dribbble

A community where designers share interface and web design work. Good for color and layout ideas.

dribbble.com

Behance

Portfolios of creative professionals, useful for seeing complete design projects and how they are presented.

behance.net

Free Icons & Images

Font Awesome

A widely used icon library with a free tier. Add icons to buttons and feature lists in one line of code.

fontawesome.com

Unsplash

Free, high-quality photos for projects. Always read the current license terms on the site.

unsplash.com

Pexels

Another source of free photos and videos, useful for galleries and landing pages. Check the license terms before use.

pexels.com

Useful Browser Extensions

WAVE

An accessibility checker from WebAIM that highlights issues like missing alt text and low contrast right on your page.

WAVE extension

Lighthouse

Built into Chrome DevTools. It audits performance, accessibility and SEO and tells you what to improve.

Lighthouse overview

axe DevTools

An accessibility testing extension that explains each problem it finds and how to fix it.

deque.com/axe

Color Palette Tools

Coolors

Generate and tweak color palettes quickly, then copy hex codes straight into your CSS.

coolors.co

WebAIM Contrast Checker

Check whether your text and background colors have enough contrast to meet accessibility guidelines.

Contrast Checker

Adobe Color

Build harmonious palettes using color theory rules such as complementary and analogous schemes.

color.adobe.com

Typography Tools

Google Fonts

A large library of free web fonts with copy-and-paste embed code. Choose one font for headings and one for body text.

fonts.google.com

Fontpair

Suggests pairings of Google Fonts, so you do not have to guess which fonts work well together.

fontpair.co

Type Scale

Preview a consistent set of font sizes so headings and text feel balanced.

typescale.com

Website Testing Tools

W3C Markup Validator

Checks your HTML for mistakes such as unclosed or misplaced tags.

validator.w3.org

W3C CSS Validator

Finds typos and invalid properties in your stylesheet.

CSS Validator

Can I use

Shows which browsers support a given HTML, CSS or JavaScript feature before you rely on it.

caniuse.com
